Welcome to the PLP Web Development Week 1 Assignment. 

This project introduces foundational concepts of modern web development, emphasizing semantic HTML5 elements, accessibility best practices, and strategies for creating SEO-friendly web pages. 
In today’s digital landscape, building websites that are both user-friendly and search engine optimized is essential. Semantic HTML5 improves the structure and readability of web pages for developers, enhances accessibility for users with disabilities, and ensures that search engines can accurately interpret and rank content. 

Through this assignment, you will learn to organize content using appropriate HTML5 tags, implement intuitive and accessible navigation, and write clear, relevant, and optimized content for search engines.

Explore the About, Features, and Contact pages to see these concepts applied
